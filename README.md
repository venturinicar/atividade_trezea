#  🌍 Quinto Projeto - Desenvolvimento WEB

Este projeto tem como objetivo entender sobre HTML e CSS e poder criar nossas páginas WEB.

## 🎯 Objetivo

Noções sobre código fonte de paginas, criação de páginas WEB usando bloco de notas, utilização da linguagem de marcação HTML, a linguagem para estilização CSS e programação e elaboração de código utilizando VS Code, noções sobre o termo IntelliSense, conceitos de inline, interno e externo, agrupamentos, Praticar criação de página utilizando VS Code.

## 🆚 Linguagem usada (HTML e CSS)

## 👨🏼‍💻Analise e Resultados

O codigo elaborado em VS Code apresenta como resultaddo uma pagina da WEB estilizada,apresentando um cabeçalho e tres colunas lado a lado onde esão mostrados tres temas e respectivas atividades relativas a cada tema. E um texto explicativo para cada tema com a legenda das atividades
